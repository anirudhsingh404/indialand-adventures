# India Travel Explorer

Make Me a opening page for my website. It's basically a travel website. Travel and itinerary planning. So I have named my website India Land, and I want my opening page to be fully animated. As soon I click on my website, India is written in big fonts, and then I scroll up. India gets scrolled up and gets placed in the website heading line near the land. Okay. And it should contain all tourist places in India. It should show suggestions and a search bar to where I want to plan my visit. And it will suggest top places from all around India. Like if I am searching Kolkata, then it should suggest all the places, minimum 10 to 15 places from Kolkata. Like this wise for all the city and its states of India.
